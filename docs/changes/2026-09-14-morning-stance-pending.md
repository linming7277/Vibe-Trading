## 新规则（`morning_macro_brief.py`）

- 新增未落地词表 `_STANCE_PENDING_KWS`：`悬念、待揭晓、待公布、预期、是否、可能、或将、料将、观望、等待决议`。
- 新增 `_landed_hits(titles, keywords)`：标题命中方向词、且**不含任一未落地词**，才计入已落地命中。
- `draft_morning_takeaway` 改为先判未落地再判冷/暖：
  - 已落地命中 `加息/上调利率/通胀高于预期/美股大跌/油价大涨` → **偏冷**；
  - 已落地命中 `降息/下调利率/宽松/刺激/美股大涨` → **偏暖**；
  - 两边都没有有效命中 → **中性**（reason 可继续引用外盘涨跌家数；两边命中也未落地的并存场景同归中性）；
  - 新闻 0 条 → **资料不足**（不变）。
- 仍只看标题词面，无 LLM。

## 风险

1. 未落地词表是枚举：新的未落地表述（如「临近决议」「按兵不动观望」）若不在表内仍会误判——词面法的固有边界，可按观察增补词表（一行改动）。
2. 「将」单独不在未落地表（「或将/料将」才算）：「将上调利率」这类"宣布将执行"语序仍判已落地——按央行动作惯例视为落地前夜，方向判定可接受。
3. 「利率上调」倒序语序不命中「上调利率」——旧有限制，本轮未扩展（扩展属判定口径进一步改动）。
