## 改了什么

1. **版式**（最多 16 行，超预算先丢最早的「链接:」行）：
   - `【隔夜要闻】`最多 6 条（国内 ≤3、海外 ≤3），组内时间新→旧；每条 `HH:MM 来源 标题`，有链接才跟一行 `链接: URL`。
   - `【要点】`最多 3 条，每条 ≤30 字，仅从标题归纳（去「界面早报｜」「【早报】」前缀）。
   - `【判断】`偏暖|中性|偏冷|资料不足 + 一句原因（只引用标题命中的关键词或外盘涨跌家数）；宏观预测 SHADOW 或资料不足时含「把握低」。
   - `【数字对照】`保持原样，无指数整段省略；`【对今日环境】`段删除（由【判断】取代）。
2. **链接**：东财条目带 `url`（见下）；RSS 解析 `<link>`；政策/公告无链接列，不渲染链接行。只认 http(s) 绝对地址，`//`补 `https:`，`/`开头补 `https://finance.eastmoney.com`，其余当无链接——**禁止编链接**。
3. **排序**：`resolve_news` 现按组内新→旧排序（带时刻的按 published 降序在前，仅日期的政策/公告按日期降序在后）。
4. **`draft_morning_takeaway(news_items, overseas_items)`** 纯函数（无模型可跑），`build_morning_macro_brief` 内部调用（不是只在发送时生成）。
5. **`morning_gate_decision(usable_overseas, news_count)`** 抽成纯函数便于测试，口径不变：要闻 0 且有效外盘 <2 → `SKIPPED_EMPTY`。

## 判断规则（纯函数）

- 标题命中 `加息 / 上调利率 / 通胀高于预期 / 美股大跌 / 油价大涨` → **偏冷**
- 标题命中 `降息 / 下调利率 / 宽松 / 刺激 / 美股大涨` → **偏暖**
- 两边都命中或都没命中 → **中性**（都没命中时原因引用外盘涨跌家数，如「要闻无方向信号，隔夜外盘 1 涨 2 跌」）
- 新闻 0 条 → **资料不足**，不编要点
- 原因只引用标题里出现的关键词（如「要闻出现『油价大涨』」），禁止荐股与交易用语（`_assert_boss_safe` 继续兜底）
