# 2026-09-09 宽度宇宙改为 A 股股票白名单

- 日期：2026-09-09
- 性质：宇宙口径单点修正。不改涨停 10%/20% 识别口径与贴板/额门槛、不改估值/outlook 其它规则、不改 Focus/价值线；未 commit；未注册 live_routes。

---

## 一、改了什么 / 为什么

宽度行（`20日新高 N 家`）的宇宙 `day_tail_universe` 只排除了北交/ST/零量，**混入指数与基金**：2026-09-08 宇宙 7689 家里约 **1829 只是 15/16/51/56/58 前缀的 ETF/LOF**（另有沪 000 指数、880/881 板块指数、深 399）。债券/红利类 ETF 在弱市持续创新高（证据：158009.SZ 被计入新高），导致 **N=1048 虚高**。

**修复**：按任务书改为**股票白名单（市场后缀 + 代码前缀）**，不做「ETF」名称模糊匹配（会误伤名字带 ETF 字样的股票/漏掉改名品种）：

| 后缀 | 保留前缀 |
|---|---|
| .SH | 600 / 601 / 603 / 605 / 688 |
| .SZ | 000 / 001 / 002 / 003 / 300 / 301 |

白名单天然排除：沪市 000 指数、880/881 板块指数、深市 399 指数、沪 50/51/52/56/58 与深 15/16 基金、北交所（43/83/87，且 bj 目录本就不扫）。既有排除（ST/*ST 名称、P 日零成交、末根对齐 P 日、盘中根裁剪）全部保留。

`scan_limit_ups`（涨停）与新高计数都走这一个函数——单点过滤，两口径同时变干净。

## 六、已知风险

2. **B 股不在宇宙**（900.SH / 200.SZ 前缀未列）——与低估值研究宇宙口径一致，属有意排除。
3. `.day` 为不复权价，除权除息日新高判定偏保守（沿用既有风险）。
