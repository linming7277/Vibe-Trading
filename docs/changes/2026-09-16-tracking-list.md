# 2026-09-16 闭环 MVP：跟踪清单（研究结论的人工批准与事后对账）

- 日期：2026-09-16
- 性质：新功能（老板拍板的闭环最小可行版）。决策链 = ①信号（Focus 分档，已有）→ ②**人工纳入跟踪**（本次新增）→ ③**参考价与现价对账**（本次新增）→ ④周度复盘（后续：复用飞书推送）。
- 情绪线不在本闭环内（老板拍板暂不开发）。**零 LLM、纯确定性读写**。

---

## 是什么

老板在「机会与风险」页把重点研究的公司**纳入跟踪**：系统记录纳入时点的参考价与当初理由；之后清单每天自动对照最新行情（现价、涨跌、跟踪天数、当前档位），让"系统说这家值得研究"变成"被行情检验过的记录"。移出跟踪保留历史，不物理删除。

## 用语与红线

面向老板只说「跟踪 / 纳入 / 移出 / 参考价 / 现价 / 涨跌」——**零交易用语**（不出现买卖/建仓/持仓/目标价）；参考价仅供研究对账，页面固定注明"不是交易记录"。

## 实现

### 后端
- 新模块 `agent/src/company_tracking/`（store + service）：表 `company_tracking_list`（research.db，stock_code 唯一，status=active/removed 软删除）。
- 参考价：纳入时自动从行情缓存取最近价（盘中每 5 分钟刷新）；取不到则置空并提示"待首个收盘数据补齐"，不编造。
- 清单视图富集：现价（同一行情缓存）、较参考价涨跌、跟踪天数、**今日 Focus 档位**（读取失败干净降级为 None，不阻断）。
- 路由（`focus_selection_routes.py`，require_auth）：`GET/POST /api/value/tracking`、`DELETE /api/value/tracking/{stock_code}`。
- 注意：本文件启用 `from __future__ import annotations`，**请求模型必须定义在模块级**（函数内类无法被 FastAPI 注解解析，会退化成 query 参数）。

### 前端（机会与风险页）
- 「重点研究」档公司卡片新增**「纳入跟踪」**按钮（已纳入显示"已纳入跟踪"徽标）；今日变化区块下方新增**「跟踪清单」**区块（目录条同步新增入口）。
- 清单行：公司 / 参考价 / 现价 / 涨跌（红绿）/ 跟踪天数 / 当前档位 / 移出按钮。
