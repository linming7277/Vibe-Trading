## 旧 16 字规则为什么失败

`compress_title(title)[:16]` 只比**前 16 个字**。三条房价标题的前 16 字分别是「8月70城房价出炉：15城环比」「国家统计局城市司高级统计师杨彩」「70城最新房价出炉」——互不相同 → 全部保留，国内席位被同一件事占满。而这条规则又太脆：任何两条前 16 字偶合的**不同事件**反而会被误并。

## 新规则（两层，纯规则无 LLM）

**层 1 — 规范化**（`_normalize_title`）：去早报类前缀、去「YYYY年M月（份）」「M月D日」「6 位以上数字」、去停用词（最新/出炉/解读/高级统计师/统计师/今日/昨日）、去全部标点与空白。

**层 2 — 主题组交集**（`_title_topics` + `_TOPIC_TERM_GROUPS`）：事件级强词组（组名=事件标识）：

| 组 | 成员词 |
|---|---|
| 房价 | 70城 / 房价 / 商品住宅 / 住宅销售 / 城市司 |
| 算力国常会 | 国常会 / 算力基础设施 |
| 光通信数据中心 | 光通信 / 数据中心 |
| 存储芯片 | 存储 / 芯片 / 半导体 |
| 美联储利率 | 美联储 / 联储 / 利率决议 / 降息 / 加息 |
| 黄金 / 原油油价 / 集采 / 国标自行车 / 十五五规划 | … |

**判重**：两标题规范化串相等，**或**主题组交集非空 → 同一事件只留一条；保留「规范化标题更长（更具体）」者，长度相同保留时间更新者。组词只收强辨识事件词——「国常会部署算力基础设施」与「光通信数据中心方案」属不同组，不再误并。

## 风险

1. 主题组是枚举：新事件类型（如「低空经济」）未入组则不判重——多条并存（不会丢内容，只是占席位）；按观察增补组词即可。
2. 「保留更长标题」在个别场景会留下标题很长但信息密度一般的条目（如统计师署名解读），可接受——它确实信息最全。
