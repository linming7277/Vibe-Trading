## 修复 1：分区——国内官方数据强制归国内

- 问题：「国家统计局：8月份规上工业原油产量1843万吨…」因标题含「原油」（海外词）被分进海外组。
- 修复：`_split_and_cap` 增加**国内强制词先判**（`_DOMESTIC_FORCE_KWS`）：
  `国家统计局 / 统计局 / 海关总署 / 央行 / 财政部 / 发改委 / 国常会 / 两部门 / 新华社`
  标题含任一 → 一律国内，即使同时出现原油/黄金/美元。

## 修复 2：解读——产量数据不再配「能源价格波动」

- 问题：「原油产量1843万吨 同比增长0.8%」被配「能源价格波动值得关注对成本端与通胀的传导。」——产量数量 ≠ 价格。
- 修复：`_interpret_lines` 新增数据型特判——标题同时命中能源品（原油/天然气/发电）与数据词（产量/同比/万吨/亿立方米/亿千瓦时）→ 改配数据向解读：
  「国内能源产量数据更新，先看供需数量，不直接等同于价格涨跌。」
- 价格句（「能源价格波动…」）只保留给明确写「油价/金价/上涨/下跌/大跌」的标题；非数据型能源标题（如「国际油价大涨 布伦特突破前高」）仍走原价格解读。宁可少一句，不错配。
